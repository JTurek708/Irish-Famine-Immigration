Abbreviations found in this documentation: 
------------------------------------------ 
CIR - Center for Immigration Research 
MHR - Manifest Header Record(s) 
MID - Manifest Identification Number 
  
  
File Names: 
---------- 
FIMHR - Famine Irish Manifest Header File - on this disk 
  3226 records - one record per manifest 
FIPAS - Famine Irish Passenger Record File - sent on nine-track
tape 
  604,596 records - one record per passenger 
FIPRT - Famine Irish Port Code List - on this disk 
  134 records - one record per port code 
FIOCC - Famine Irish Occupation Code List - hard copy sent in
1982 
FICTY - Famine Irish Country Code List - on this disk 
   33 records - one record per country code
